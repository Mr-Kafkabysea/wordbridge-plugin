# 第三方依赖

## pywin32 312

- 用途：通过 Python 访问 Windows COM，作为连接桌面 Word 的基础依赖。
- 必要性：首版采用 Windows Word COM 路线，需要 Python 与 COM 之间的桥接能力。
- 安装来源：<https://pypi.org/project/pywin32/312/>。
- 上游代码：<https://github.com/mhammond/pywin32>。
- 许可证：项目标识为 PSF-2.0，但包含其他许可的代码；具体以对应版本源码中的许可证文件及各文件版权声明为准。
- 采用方式：安装上游发布的 wheel 到项目 `.venv`，不复制源码、不运行全局安装后处理脚本。
- 版本管理：在 `requirements.txt` 固定版本。升级时重新验证导入、COM 初始化和真实 Word 操作。

依赖能够导入及 COM 能够初始化，不代表已经验证 Word 连接或文档读写。

## mcp 2.2.0

- 用途：通过官方 Python SDK 将既有 Word 操作封装成 MCP 工具，并建立测试客户端。
- 必要性：处理 MCP 初始化、工具发现、参数与结果传输；Word 操作本身继续使用 `pywin32`。
- 安装来源：<https://pypi.org/project/mcp/2.2.0/>。
- 上游代码：<https://github.com/modelcontextprotocol/python-sdk/tree/v2.2.0>。
- 许可证：MIT；安装包及其传递依赖保留各自许可证。
- 采用方式：只安装基础 `mcp` 包及其必需依赖，不安装 CLI 扩展，不安装独立的 `fastmcp` 包。
- 版本管理：在 `requirements.txt` 固定为 2.2.0，使用 v2 API，避免混入旧版 SDK 示例。
- 本阶段传输：本地 stdio（标准输入/输出），不监听网络端口。

## pydantic 2.13.5

- 用途：定义并严格校验 MCP 写入确认表单，要求 `confirm` 为布尔值，拒绝字符串冒充确认。
- 必要性：官方 MCP SDK 的确认接口使用 Pydantic 模型。
- 来源：<https://pypi.org/project/pydantic/2.13.5/>；上游 <https://github.com/pydantic/pydantic>。
- 许可证：MIT，本机安装包元数据已核对。
- 采用方式：已经作为 MCP 的必需依赖安装，本步因代码直接导入，提升为显式固定版本依赖；未新增安装操作或复制第三方源码。
